# DP Graph Builder

Построитель графиков функций для Android и настольных систем. Формула
вводится в главном меню, сохраняется на устройстве и открывается на
интерактивной координатной плоскости с управлением жестами.

## Возможности

* **Язык формул** — скобки, вложенные вызовы, 40 функций, неявное умножение
  (`2x`, `3sin(x)`), условия и кусочно заданные функции.
* **Список формул** — сохраняется на диск, переживает перезапуск; последняя
  использованная всегда стоит в поле ввода.
* **Жесты** — один палец двигает оси, два пальца меняют масштаб.
* **Понятные ошибки** — с указанием позиции и подсказкой имени.
* Работает офлайн, разрешений не требует.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Сборка APK

```bash
pip install buildozer
buildozer -v android debug        # результат появится в bin/
```

## Тесты

```bash
pip install pytest
python -m pytest                  # парсер, геометрия, хранилище
xvfb-run -a python -m pytest      # плюс тесты интерфейса
```

Тесты интерфейса требуют графического вывода и без него автоматически
пропускаются.

# Язык формул

Формула — выражение относительно переменной `x`. Регистр не важен: `SIN(X)`
и `sin(x)` — одно и то же. Полная справка доступна в самом приложении по
кнопке «Справка».

## Числа и константы

```
12      3.14      .5      1.6e-19      3e8
```

| Имя | Значение |
|-----|----------|
| `x` | переменная, по которой строится график |
| `pi` | 3.14159... |
| `e` | 2.71828... |
| `tau` | 2π |
| `phi` | золотое сечение |

## Операторы

Ниже — по убыванию приоритета.

| Оператор | Смысл |
|----------|-------|
| `a!` | факториал (через гамма-функцию, определён и для дробных) |
| `a ^ b` | степень, **правоассоциативна**: `2^3^2` = 2^(3^2) = 512 |
| `-a` | смена знака; слабее степени, поэтому `-x^2` = −(x²) |
| `a * b`, `a / b`, `a % b` | умножение, деление, остаток |
| `a + b`, `a - b` | сложение, вычитание |
| `<` `>` `<=` `>=` `==` `!=` | сравнения, дают 1 или 0 |

Присваивания нет; `=` отдельно от `==` считается ошибкой.

## Неявное умножение

Знак умножения можно опускать там, где это однозначно:

```
2x          =  2*x
3sin(x)     =  3*sin(x)
2(x+1)      =  2*(x+1)
(x+1)(x-1)  =  (x+1)*(x-1)
```

Исключение — два числа подряд: `2 3` — ошибка, потому что без пробела это
было бы число `23`.

## Функции

| Группа | Функции |
|--------|---------|
| Тригонометрия | `sin` `cos` `tan` `cot` `sec` `csc` |
| Обратная | `asin` `acos` `atan` `acot` `atan2(y, x)` |
| Гиперболические | `sinh` `cosh` `tanh` `asinh` `acosh` `atanh` |
| Степени и корни | `sqrt` `cbrt` `root(n, x)` `exp` |
| Логарифмы | `ln` `lg` `log2` `log(b, x)` |
| Округление | `abs` `sign` `floor` `ceil` `round(x[, n])` `trunc` `frac` |
| Выбор | `min(...)` `max(...)` `clamp(x, a, b)` `hypot(...)` `mod(a, b)` |
| Прочее | `gamma` `deg` `rad` `if(условие, a, b)` |

Ветви `if` вычисляются лениво: в `if(x > 0, ln(x), 0)` логарифм на
отрицательных `x` просто не считается и разрыва не даёт.

## Область определения

Деление на ноль, `ln` неположительного, `sqrt` отрицательного, `asin` вне
`[-1, 1]` — не ошибки. График в таких точках разрывается. Вертикальные
асимптоты тоже показываются разрывом, а не отвесной чертой через экран.

## Примеры

```
x^2 - 3                  парабола со сдвигом
sin(x)/x                 затухающие колебания
sqrt(abs(x))             корень из модуля
x - floor(x)             пила
if(x > 0, ln(x), -ln(-x)) кусочно заданная функция
2sin(x) + cos(3x)        сумма гармоник
root(3, x)               кубический корень, включая x < 0
```

## Устройство проекта

```
main.py                точка входа (обязательное имя для сборки APK)
DP_Graph_Builder.py    запуск под историческим именем
dp_graph/
    expression.py      лексер, сортировочная станция, компиляция в замыкания
    plotting.py        геометрия окна, выборка точек, сетка (без Kivy)
    storage.py         список формул на диске
    graphview.py       холст графика и жесты
    app.py             экраны и переходы
    help_text.py       справка, собранная из таблиц парсера
    theme.py           палитра и метрики
tests/                 146 тестов
```

Формула разбирается **один раз** при вводе и компилируется в дерево
замыканий; вычисление точки стоит около 1.3 мкс, поэтому перерисовка при
жестах идёт без задержек. `plotting.py` не зависит от Kivy — вся геометрия
покрыта обычными тестами.

Перечень функций в справке не дублируется вручную, а строится из таблиц
`expression.py`: добавленная в таблицу функция сразу доступна в формулах и
описана в справке.
